# План развития

## Первый выпуск

- Два режима мастера: существующий host AWG и новая установка AWG 3.1.
- Самостоятельный Telegram-бот и OpenClaw-адаптер.
- Клиенты, QR/файл, переименование, блокировка, удаление с подтверждением.
- Импорт серверных peer-секций, честная отметка отсутствующих приватных ключей.
- Квоты, срок, cron и уведомления без модели.
- Проверки импорта и отказ от неподдерживаемых топологий.

## Следующий выпуск

- Изолированный end-to-end тест обеих установок на чистой VM с реальным Telegram.
- Транзакционное обновление с версионированными миграциями, backup/restore.
- Выбор часового пояса и языка RU/EN в мастере.
- Ожидание ввода отдельно по темам с нормализованным ID контекста.
- Docker backend без перехвата управления чужими контейнерами.
- Импорт клиентских файлов по совпадению публичных ключей без перевыпуска.
- Несколько интерфейсов и поиск клиентов.
- Сохранение полного peer-блока, IPv6 и site-to-site.
- Уточнение статистики при рестартах и атомарное выполнение расписаний.
- Режим локальной сети напрямую как отдельный клиентский профиль.

## Интерфейс

Главная: Клиенты, Добавить, Расписания, Состояние.
Карточка: статус, адрес, handshake, трафик, срок, квота, QR/файл,
доступ/лимиты, переименование, дополнительные действия.
После изменения показывается обновлённая карточка; опасные действия
подтверждаются отдельно. Общение с моделью не входит в обязательный путь.
